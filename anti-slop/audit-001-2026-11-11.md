# Antislop UI & Design Audit — 001 (2026-11-11)

**Mode:** `after` (Audit before modification)
**Scope:** `public/assets/common.css`, `public/assets/common.js`, `public/format.js`, `public/index.html`, `public/traffic.html`, `public/devices.html`, `public/device.html`, `public/summary.html`

---

## HIGH Priority — Hard Gate Violations

1. **[HIGH] [R-25] Status & delay badges fail WCAG AA color contrast (`public/assets/common.css`, `public/format.js`)**
   - **Reason:** `.badge` mixes `--c` at 14% with white while keeping `--c` as the text color, producing contrast ratios of `1.51:1` (yellow `#ffc107`), `2.71:1` (green `#28a745`), and `3.70:1` (red `#dc3545`), all below the 4.5:1 minimum.

2. **[HIGH] [R-25] Sidebar brand subtitle fails WCAG AA color contrast (`public/assets/common.css`)**
   - **Reason:** `.brand small` uses `#64748b` text on `#0f172a` background (`3.75:1`), falling below the required `4.5:1` contrast ratio for 11px normal text.

3. **[HIGH] [R-32] Sortable table headers and interactive links/buttons lack full keyboard navigation and visible focus rings (`public/assets/common.css`, `public/assets/common.js`)**
   - **Reason:** `th.sortable` only responds to mouse clicks without keyboard focusability (`tabindex="0"`, `Enter`/`Space` activation, `aria-sort`), and `.nav a`, `.btn-primary`, and `button` lack a high-contrast `:focus-visible` indicator.

4. **[HIGH] [R-39] Incomplete interaction affordances, missing form labels, and unguarded motion (`public/assets/common.css`, `public/assets/common.js`, `public/*.html`)**
   - **Reason:** Enabled controls (`a.btn-primary`, `select`, `input[type="date"]`) lack a unified `cursor: pointer` and distinct `:hover`/`:active`/`:disabled` states (`button:disabled` uses `cursor: default` instead of `not-allowed`), filter/search fields and icon-only Time Range Picker buttons lack accessible labels, and CSS transitions/animations do not respect `prefers-reduced-motion: reduce`.

5. **[HIGH] [R-03] Sub-44px mobile touch targets, two-state-only breakpoint, and non-fluid typography (`public/assets/common.css`)**
   - **Reason:** Interactive controls (`.btn-primary`, pagination buttons, `.trp-bar button`, selects) measure 24–32px tall instead of the 44×44px mobile minimum, layout only switches at a single `800px` breakpoint without tablet reflow, and typography uses fixed pixel sizes instead of fluid `clamp()`.

6. **[HIGH] [R-27] Missing initial loading states and non-actionable empty/error states across data views (`public/assets/common.js`, `public/*.html`)**
   - **Reason:** KPI containers (`#kpis`) and tables render empty prior to the first fetch without a visible loading state, empty states show bare text without cause/action context, and failed fetches only change the `#conn` pill without displaying an actionable error state in the view.

7. **[HIGH] [R-37] Missing design direction and liveliness dials (`DESIGN.md` / `public/assets/common.css`)**
   - **Reason:** The UI was built without an explicit `DESIGN.md` or declared liveliness dials (`ENERGY / RHYTHM / MOTION`), resulting in a flat, sterile default layout without intentional visual hierarchy.

8. **[HIGH] [R-40] Render-blocking third-party scripts in `<head>` (`public/index.html`, `public/traffic.html`, `public/devices.html`, `public/device.html`, `public/summary.html`)**
   - **Reason:** Third-party CDN scripts (`chart.umd.min.js` and `xlsx.full.min.js`) load synchronously in `<head>` without `defer`, delaying first paint.

## MEDIUM Priority — Purpose-Gate Violations

9. **[MEDIUM] [R-06] Unloaded default font, wide-tracked uppercase card titles, and non-tabular numbers (`public/assets/common.css`)**
   - **Reason:** `Inter` is declared without loading a webfont (falling back to OS system fonts), every `.card h3` defaults to uppercase with wide tracking (`0.04em`), and numeric telemetry columns/KPIs omit `font-variant-numeric: tabular-nums`.

10. **[MEDIUM] [R-04] Decorative emoji used as UI icons in Time Range Picker (`public/assets/common.js`)**
    - **Reason:** `createTimeRangePicker` uses raw OS emoji (`🕒`, `📅`, `📋`, `📥`) for clock, calendar, copy, and paste controls instead of crisp, consistent SVG icons suited to an operations dashboard.

11. **[MEDIUM] [R-12] Uniform shadow applied to every card without elevation hierarchy (`public/assets/common.css`)**
    - **Reason:** Every `.card` and `.trp-bar` receives the same default shadow (`--shadow`), flattening visual hierarchy instead of reserving elevation for interactive or floating surfaces (popovers, sticky topbar, hoverable link cards).

12. **[MEDIUM] [R-14] Identical visual weight across all KPI and content cards (`public/assets/common.css`, `public/*.html`)**
    - **Reason:** Primary health indicators (`Total offline`, `Total devices delay > 5s`) use the exact same card styling, border, and typography as secondary summary cards, with no semantic accent or hierarchy differentiation.

## LOW Priority — Quality Locks

13. **[LOW] [R-20] Generic template visual identity (`public/assets/common.css`)**
    - **Reason:** The dashboard uses default slate/blue boilerplate styling with unstyled native `<select>` and `<input>` elements, lacking a cohesive IT Operations telemetry identity motif, refined table density, and modern control styling.

14. **[LOW] [R-29] Fragmented and excessive color palette across files (`public/format.js`, `public/assets/common.css`, `public/traffic.html`)**
    - **Reason:** Status colors mix legacy Bootstrap hexes (`#28a745`, `#ffc107`, `#dc3545`) in `format.js` with Tailwind hexes (`#16a34a`, `#f59e0b`, `#dc2626`) in `common.css`, while `traffic.html` introduces a 7-color hardcoded `PALETTE` instead of a unified 2–3 core + 1 accent token system.

15. **[LOW] [R-11] Ad-hoc border radius values (`public/assets/common.css`)**
    - **Reason:** Components hardcode six different radii (`12px`, `10px`, `8px`, `6px`, `5px`, `999px`) rather than using a systematic radius scale (`--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-pill`).

16. **[LOW] [R-21] Fixed single-theme layout without Dark/Light mode toggle (`public/assets/common.css`, `public/assets/common.js`)**
    - **Reason:** Although IT Operations monitoring dashboards are frequently used in dim NOC environments as well as bright offices, the UI ships a fixed light canvas without a working Light/Dark theme toggle.

## Follow-Up Remediation Report (Approved Items: 1–16)

All 16 findings approved by the user have been resolved:

1. **#1 [R-25] Fixed:** Replaced low-contrast `color-mix` badge styles with semantic badge tokens (`.badge-ok`, `.badge-warn`, `.badge-err`, `.badge-info`) in `public/assets/common.css` and `public/assets/common.js`, achieving `6.37:1`–`7.58:1` WCAG AA contrast across both Light and Dark themes.
2. **#2 [R-25] Fixed:** Updated `.brand small` in `public/assets/common.css` to `#94a3b8` on `#0b1120` (`7.34:1` contrast ratio).
3. **#3 [R-32] Fixed:** Added `tabindex="0"`, `aria-sort`, and `Enter`/`Space` keyboard handlers to all `th.sortable` headers in `public/assets/common.js`, plus a `2px solid var(--focus-ring)` `:focus-visible` indicator on all interactive elements in `public/assets/common.css`.
4. **#4 [R-39] Fixed:** Added base-layer `cursor: pointer` and `cursor: not-allowed` rules, distinct `:hover`/`:active`/`:disabled` states, explicit `<label>` and `aria-label` attributes on all inputs/selects/icon buttons, `scope="col"` on table headers, and `@media (prefers-reduced-motion: reduce)` support.
5. **#5 [R-03] Fixed:** Implemented fluid typography via `clamp()`, a 3-stage responsive layout (`> 1024px` desktop, `641px–1024px` tablet, `<= 640px` mobile), and `44px` minimum touch targets on mobile breakpoints.
6. **#6 [R-27] Fixed:** Added initial loading states for KPI strips and tables, informative empty states explaining cause and next action, and an actionable `#pageError` banner with a `Retry now` button in `public/assets/common.js` and `public/summary.html`.
7. **#7 [R-37] Fixed:** Created `DESIGN.md` declaring the Design Read, Liveliness Dials (`ENERGY 2 / RHYTHM 2 / MOTION 1`), Liveliness Levers, and the one-line decision log (`R-31`).
8. **#8 [R-40] Fixed:** Added `defer` to all `<script>` tags in `<head>` across `public/index.html`, `public/traffic.html`, `public/devices.html`, `public/device.html`, and `public/summary.html`.
9. **#9 [R-06] Fixed:** Loaded `Plus Jakarta Sans` and `JetBrains Mono` (`display=swap`), removed forced wide-tracked uppercase from `.card h3`, and applied `font-variant-numeric: tabular-nums` to all KPIs, badges, pills, and tables.
10. **#10 [R-04] Fixed:** Replaced raw OS emoji (`🕒`, `📅`, `📋`, `📥`) in `createTimeRangePicker` with crisp inline monochrome SVG icons (`ICONS` in `public/assets/common.js`).
11. **#11 [R-12] Fixed:** Removed uniform drop shadows from data cards (keeping crisp `1px` structural borders) and reserved `--shadow-sm` / `--shadow-lg` for the sticky `.topbar`, interactive `.link-card:hover`, and floating `.trp-popover`.
12. **#12 [R-14] Fixed:** Added semantic KPI card hierarchy (`data-tone="primary" | "ok" | "warn" | "err"`) with top-border accents so critical operational counters (`Total offline`, `Total devices delay > 5s`, `Latest delay`) stand out immediately.
13. **#13 [R-20] Fixed:** Established a modern industrial-telemetry aesthetic with tabular monospace identifiers, bordered scroll-wrapped tables, and unified control styling in `public/assets/common.css`.
14. **#14 [R-29] Fixed:** Unified status colors across `public/format.js`, `public/assets/common.css`, and `public/traffic.html` into a disciplined 3-core + 1-accent + semantic token system.
15. **#15 [R-11] Fixed:** Standardized border radii using `--radius-sm` (`6px`), `--radius-md` (`8px`), `--radius-lg` (`12px`), and `--radius-pill` (`999px`).
16. **#16 [R-21] Fixed:** Implemented a persistent Light/Dark theme toggle (`#themeToggle`) in the topbar that updates CSS custom properties and Chart.js canvas tokens dynamically.
